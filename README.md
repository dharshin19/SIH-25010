## Problem Title  
**SIH 25010: Smart Crop Advisory System for Small and Marginal Farmers**

## Problem Description  
Small and marginal farmers, who constitute 86% of India’s agricultural workforce (NABARD, 2022), often rely on informal and outdated methods for crop planning, pest control, and fertilizer usage. These practices are not only inefficient but also environmentally harmful. The absence of personalized, real-time advisory tools—especially those tailored to local languages and low digital literacy—exacerbates the problem. This results in poor yields, high input costs, and unsustainable farming practices.

## Impact / Why This Problem Needs to Be Solved  
Solving this issue will empower farmers with scientific decision-making tools, reduce reliance on unreliable sources, and promote sustainable agriculture. It will enhance food security, improve rural livelihoods, and support India's broader goals under Digital India and Smart Farming initiatives.

## Proposed Solution  
We propose a Smart Crop Advisory System that leverages AI, cloud computing, and IoT to deliver personalized, real-time agricultural guidance. The system will:

- Recommend crops based on soil type, climate, and market demand  
- Provide fertilizer guidance using AI models trained on soil nutrient data  
- Diagnose pests and diseases via image uploads using CNN-based models  
- Integrate weather forecasts for timely sowing, irrigation, and harvesting  
- Track and predict market prices using agri-market APIs  
- Offer voice-enabled, regional language support  
- Operate offline via SMS/USSD for low-connectivity areas  

### Innovation and Uniqueness  
- Multilingual voice interface for inclusivity  
- AI-driven pest detection and crop recommendation  
- Offline advisory support for remote regions  
- Feedback loop for continuous model improvement  

## Technical Approach  
**Technologies Used:**  
- **Frontend:** Flutter/React Native for mobile app  
- **Backend:** FastAPI/Django with cloud microservices (AWS/GCP)  
- **Database:** PostgreSQL with PostGIS, MongoDB for image data  
- **AI/ML Models:**  
  - CNN for pest/disease detection  
  - Random Forest/XGBoost for crop/fertilizer recommendations  
  - LSTM/ARIMA for weather prediction  
- **IoT Integration:** Soil moisture and pH sensors (GSM/LoRaWAN)  
- **External APIs:** IMD Weather API, ISRO satellite data, Agmarknet  

**Implementation Methodology:**  
1. Farmer registers and inputs basic farm details  
2. App fetches soil/weather data and runs AI models  
3. Advisory is delivered via text, voice, or image-based feedback  
4. Farmers upload crop images for pest diagnosis  
5. Market prices and alerts are pushed regularly  
6. Feedback is collected to refine recommendations
